# Movie Recommendation System

A machine learning based movie recommendation system built using Python and Streamlit.

## Overview
This project recommends movies similar to the one selected by the user. It uses content-based filtering and cosine similarity to find related movies.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit

## Features
- Movie recommendation based on similarity
- Interactive web interface
- Fast recommendation results

## How to Run

1. Install dependencies:
pip install -r requirements.txt

2. Run the app:
streamlit run app.py

## Project Files
- app.py → Streamlit web application
- Movierecommendation.ipynb → Jupyter notebook version
- movie.pkl / movie_dict.pkl → processed movie data
